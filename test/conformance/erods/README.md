# eRODS output-file conformance fixtures (MB-12 / mobile future.md F-11)

Each case is three files:

| file | what |
|---|---|
| `NN_name.input.json` | the TS `OutputFileInput` (dates as ISO strings) + `fileNameInput { rangeStart, rangeEnd, sequence }`; the file name's creation date is `generatedAt` in `driver.timezoneOffsetMin` |
| `NN_name.expected.csv` | bytes written by `backend/src/modules/transfers/output-file.ts` `buildOutputFile()` (CRLF) |
| `NN_name.expected.json` | `fileName` (`filename.ts`), `fileCheckValue`, `lineCount`, `sizeBytes`, TS validator `counts` |

The expected files are **generated by the backend TypeScript code itself** (read-only use; the
backend is not modified) and every case passes the TS `validateOutputFile()` before it is written:

```sh
cd backend
TS_NODE_TRANSPILE_ONLY=1 TS_NODE_PROJECT=tsconfig.json \
  node_modules/.bin/ts-node test/conformance/erods/generate.ts test/conformance/erods
```

The mobile app's Dart port (`mobile/lib/data/transfer/output_file_builder.dart`, `filename.dart`,
`output_file_validator.dart`) must reproduce them byte-for-byte:
`mobile/test/data/transfer/erods_conformance_test.dart`.

All cases use ELD Identifier `OBK001` — **6 characters** (Appendix A 7.15, backend B-138); the
ELD Registration ID stays 4 (`OBK1`, 7.17).

Cases:

1. `01_full_8day` — the backend's own `output-file.fixture.ts`: every segment populated
   (including login/logout and engine power-up/shut-down), superseded (status 2) + edited
   (origin 2) records, PC 10-mile precision, sequence id 65535, 80-char annotation, non-ASCII
   comment, current position, accumulated miles / elapsed hours → `SMITH3841091126-000000000.csv`.
2. `02_empty_codriver_exempt` — no records at all, co-driver header line, exempt driver, 60/7
   basis, empty registration id (TEST mode), comment with commas / CRLF / tab and > 60 chars,
   non-ASCII names, unknown current position (`X`,`X`) → `OBRIE2113011525-000000011.csv`.
3. `03_dst_fallback_day` — America/New_York fall-back day (Nov 2 2025, 25 h): per-event offsets
   −240 → −300, rounding ties (0.125, −72.125, 4321.45), `-0.001` → `0.00`, sequence wrap
   65536 → `0000` and 0 → `0000` (7.24), sequence 100 → suffix `000000099`
   → `NG___0707110225-000000099.csv`.

The layout was diffed column by column against the official eCFR text of 49 CFR 395 Subpart B
Appendix A (2026-10-06, `backend/docs/fmcsa/49cfr395-subpartB-appendixA.txt`) on 2026-10-08 —
backend decisions D-024 is closed. Every format change of that diff is listed for the Dart port
in `backend/docs/erods-changes-2026-10-08.md`.
